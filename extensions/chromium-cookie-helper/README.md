# Soundtify Cookie Helper

Chromium extension for copying a YouTube Music Cookie header into Soundtify.

## Install

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this folder:
   `extensions/chromium-cookie-helper`

## Use

1. Login to `https://music.youtube.com` in the same browser.
2. Open the extension popup.
3. Click `Copy Cookie Header`.
4. In Soundtify, paste into the Search box.
5. Go to `Account Manager -> ytmusic -> Paste cookie from Search`.

## Privacy

The extension only reads YouTube/Google cookies after you press a popup button.
It does not send cookies to any remote server. It only copies the Cookie header to your clipboard.
